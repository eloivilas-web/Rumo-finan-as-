# Rumo — Controlo Financeiro

Aplicação web privada para organizar comissões variáveis, despesas obrigatórias e dívidas.

## Publicação

- Cloudflare Worker existente: `round-dew-4da9`
- Branch: `main`
- Comando: `npx wrangler deploy`
- Ficheiros estáticos: `public/`
- Dados pessoais guardados no projeto Supabase do próprio utilizador, não no GitHub.

## Segurança

Nunca colocar chaves secretas, palavras-passe, tokens pessoais ou registos financeiros neste repositório.

## Dados

Antes de atualizar a aplicação, exportar um backup JSON no menu Proteção. Confirmar que os formulários de despesas e dívidas guardam os dados e que o estado apresenta a sincronização na nuvem.
